Guía — Flujo de triage de correos en n8n

Paso a paso para instalar y activar la Skill 1 (Triage de correos), que clasifica el mail entrante en Urgente / Delegar / Informativo todos los días hábiles a las 8:00 AM.
Mail Intelligence — 75% completo · Skill de triage documentada, activación pendiente
1 · Conectar Gmail a n8n
Base lista
En n8n, agregar credencial de tipo Gmail OAuth2. Autorizar con la cuenta de correo que se quiere triagear. n8n va a pedir permisos de lectura y, más adelante, de envío.
Nodo: Gmail Trigger o Gmail → Get Many · Auth: OAuth2
2 · Schedule Trigger
Listo
Dispara el flujo automáticamente de lunes a viernes a las 8:00 AM. Es el mismo patrón usado en el Monitor ETH Diario.
Cron: 0 8 * * 1-5
3 · Traer correos del día
Listo
Nodo Gmail configurado para traer los correos recibidos desde el último chequeo (o las últimas 24hs). Filtrar por bandeja de entrada, excluyendo spam y promociones.
Filtro sugerido: after: fecha del último run
4 · Code (JS) — estructurar los datos
Listo
Parsea remitente, asunto y cuerpo de cada correo en un formato limpio (JSON) para que Claude pueda clasificarlos sin ruido de headers ni HTML.
5 · Basic LLM Chain + Anthropic — clasificación
Listo
Claude clasifica cada correo en Urgente, Delegar o Informativo, con una razón breve por clasificación. El prompt está documentado en sistema-automatizacion-directora-arte.md.
Modelo sugerido: Claude API · Output: JSON con categoría + razón por correo
6 · Gmail Send — informe de triage
Pendiente
Arma y envía un correo resumen con los correos agrupados por categoría. Este es el mismo tipo de nodo pendiente en el flujo del Monitor ETH.
To: tu email · Subject: Triage diario — [fecha] · Message: reporte generado por Claude
7 · Activar el workflow
Pendiente
Toggle de Inactive a Active en la esquina superior derecha del editor de n8n. Sin este paso, el flujo queda guardado pero no corre solo.
Checklist antes de activar
  • Credencial de Gmail OAuth2 conectada y probada con una ejecución manual
  • Prompt de clasificación revisado — confirmar que las 3 categorías (Urgente / Delegar / Informativo) tienen criterios claros
  • Nodo Gmail Send configurado con el destinatario correcto
  • Ejecución manual de prueba completa, de punta a punta, antes de activar el cron
  • Confirmar que el flujo respeta la regla de oro: no envía ni reenvía correos sin que el reporte pase primero por el operador
Referencias rápidas

Categorías de triage

  • Urgente — requiere acción o respuesta el mismo día
  • Delegar — puede resolverlo otra persona del equipo
  • Informativo — solo para conocimiento, sin acción requerida

Cómo se conecta con el resto del módulo

  • Alimenta la Skill "Agenda automática" (8:15 AM)
  • Se junta con el resumen de Zoom en el "Informe consolidado" (6:30 PM)
  • Corre en paralelo al Monitor ETH Diario, en el mismo entorno de n8n local
