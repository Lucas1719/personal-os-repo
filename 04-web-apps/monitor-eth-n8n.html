1–2. Schedule Trigger + Precio simple
Listo
Dispara todos los días a las 8:00 AM. El segundo nodo trae el precio spot de ETH desde CoinGecko con una llamada liviana, útil para chequeos rápidos.
3. Datos completos ETH
Listo
Segunda llamada a CoinGecko trayendo variación 24h, 7d, volumen y otros indicadores que el nodo de análisis va a necesitar.
4. Code (JS) — parseo
Listo
Combina las dos respuestas de CoinGecko en un único objeto JSON limpio: precio, cambio 24h, cambio 7d, volumen — listo para pasarle a Claude.
5. Basic LLM Chain + Anthropic
Listo
Claude analiza los datos y redacta el reporte diario: tendencia, volatilidad, señal semafórica (verde/amarillo/rojo) y contexto respecto al ATH.
6. Google Sheets — log
Listo
Guarda cada ejecución en la hoja "Monitor ETH Log": fecha, precio, cambios, volumen, señal y el reporte completo. Es la base de datos histórica del sistema.
7. Gmail Send
Pendiente
Envía el reporte generado al mail del operador. To: email personal · Subject con el precio del día · Message con el reporte completo de Claude.
8. Fear & Greed Index
Pendiente
HTTP Request a https://api.alternative.me/fng/?limit=1. El resultado se suma al prompt de Claude para enriquecer la señal del reporte.
  1. Confirmar que n8n está corriendo en localhost:5678 y que el flujo "Monitor ETH Diario v1" aparece en la lista de workflows.
  2. Agregar el nodo Gmail Send al final del flujo, conectado a la salida del nodo Google Sheets. Configurar credencial OAuth2 de Gmail si todavía no está conectada.
  3. Agregar el nodo HTTP Request para Fear & Greed, apuntando a https://api.alternative.me/fng/?limit=1. No requiere API key.
  4. Actualizar el prompt del nodo Anthropic para que incluya el valor de Fear & Greed recibido, y lo mencione en el reporte junto a la señal semafórica.
  5. Ejecutar el flujo manualmente desde el botón "Execute Workflow" y verificar que cada nodo se ejecute sin errores, de punta a punta.
  6. Confirmar que llega el mail con el reporte completo y que la fila se agregó correctamente en Google Sheets.
  7. Activar el workflow — toggle de Inactive a Active, arriba a la derecha del editor.
